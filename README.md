# SouthParkFrameWork-extended

![South Park Banner](https://etgeekera.com/wp-content/uploads/2013/05/south-park-the-stick-of-truth-banner.jpg)

**SouthParkFrameWork-extended** is an open-source modding and research framework for **South Park: The Stick of Truth**.

The project aims to make modding, reverse engineering, and experimenting with the game easier.

## Features

- `XINPUT1_3.dll` proxy loader
- DirectX 9 hooking
- ImGui in-game menu
- DLL mod loader
- File patching and replacement
- Debug logging
- Borderless fullscreen support
- MinHook integration
- OAF archive extractor with drag-and-drop support
- Experimental multiplayer research

## Requirements

You must own your own legitimate copy of **South Park: The Stick of Truth**. Game files are not provided.
